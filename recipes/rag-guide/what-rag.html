Что такое RAG

Конвейер: запрос проходит слева направо через поиск по векторному индексу и сборку контекста, прежде чем модель формирует ответ со ссылками. Нажмите узел, чтобы заглянуть внутрь.

  1. 01Запросвопрос пользователя
  2. 02Эмбеддинг запросатекст -> вектор (1536 чисел)
  3. 03Векторный индекс (ANN)поиск ближайших соседей по косинусу
  4. 04Топ-k фрагментовk = 3 лучших по сходству
  5. 05Сборка контекстаинструкция + фрагменты + вопрос -> промпт
  6. 06LLMгенерация ответа по контексту
  7. 07Ответ со ссылкамикаждое утверждение - со ссылкой на источник

RAG отвечает на вопрос не по памяти модели: запрос кодируется в вектор, по нему ищутся ближайшие фрагменты ваших документов, top-k фрагментов собираются в промпт, и модель пишет ответ со ссылками строго по этому контексту. Включите JavaScript, чтобы пройти конвейер по шагам и заглянуть внутрь каждого узла.
