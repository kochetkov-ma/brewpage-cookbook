Зачем нужен RAG

Один вопрос, два тракта: слева модель отвечает из памяти, справа - по источнику. Сравнение и есть урок.

Вопрос: "Какой лимит загрузки файлов на тарифе Pro?" ответ недавно изменился - память модели устарела

Почему ответ справа лучше

Без RAG

Модель отвечает из памяти - извлечения нет

Запрос Вопрос пользователя "Какой лимит загрузки файлов на тарифе Pro?"
LLM - только веса Ответ из замороженных знаний training cutoff: обучение до 2024-06. Свежего источника нет - ответ собран из весов. веса заморожены - извлечения нет
Ответ "Лимит - 100 файлов." источник не указан - данные могли устареть возможна галлюцинация
С RAG

Модель отвечает по найденному источнику

Запрос Вопрос пользователя "Какой лимит загрузки файлов на тарифе Pro?"
Эмбеддинг Вопрос -> вектор текст кодируется в вектор размерности 1536 для поиска по смыслу
Векторный индекс - топ-k Поиск свежих фрагментов найден чанк limits.md (обновлён сегодня), cosine 0.94
Сборка контекста Фрагмент -> промпт LLM найденный текст подкладывается в запрос как опора - grounding
Ответ со ссылкой "На Pro - до 500 файлов, суммарно 20 МБ [1]." [1] limits.md, разд. 2 - источник обновлён сегодня опора на источник - есть цитата

Почему ответ справа лучше

1Свежие и приватные данные без переобучения. RAG подкладывает источник в момент ответа.
2Меньше выдуманных фактов. Ответ опирается на найденный текст (grounding).
3Ссылки на источники. Цитата [1] ведёт к документу и разделу.
4Дешевле дообучения. Обновить документ в индексе - минуты.

Включите JavaScript, чтобы увеличить этапы тракта.
