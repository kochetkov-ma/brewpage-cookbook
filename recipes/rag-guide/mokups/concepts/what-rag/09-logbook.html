Что такое RAG

RAG это способ дать модели доступ к вашим документам прямо во время ответа. Аббревиатура расшифровывается как Retrieval-Augmented Generation - поиск, дополнение, генерация.

Запись в журнале

Журнал заполняется сам по мере прохождения запроса. Нажмите строку, чтобы приблизить её этап на карте.

Запрос проходит весь путь

Зелёный запрос движется по линии: Запрос -> Индекс -> Топ-k -> Контекст -> Модель -> Ответ. Журнал слева пишется в такт. Нажмите строку или узел, чтобы приблизить этап.

Пример: вопрос -> находим 3 фрагмента из вашей базы -> модель отвечает по ним.

Запрос -> Индекс найти фрагменты -> Топ-k 3 ближайших -> Контекст добавить в запрос -> Модель ответ по фактам Модель отвечает по вашим документам, а не из памяти.
