Что такое RAG

RAG это способ дать модели доступ к вашим документам прямо во время ответа. Аббревиатура расшифровывается как Retrieval-Augmented Generation — поиск, дополнение, генерация.

Запрос
Вопрос
Зелёный сигнал-запрос отправлен в гавань данных.
Retrieval
Поиск по индексу
Находим нужные фрагменты в векторной базе.
Augmented
Сборка контекста
Топ-k фрагментов добавляются в запрос к модели.
Generation
Модель (LLM)
Ответ по этим фрагментам, со ссылками.
Клик по объекту приближает камеру внутрь
зелёный сигнал = ваш запрос

Пример. Вопрос → находим 3 абзаца из вашей базы → модель отвечает по ним. Итог: модель отвечает по фактам из ваших документов, а не из памяти.
