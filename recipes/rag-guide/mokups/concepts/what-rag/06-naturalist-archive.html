Что такое RAG

RAG это способ дать модели доступ к вашим документам прямо во время ответа. Аббревиатура расшифровывается как Retrieval-Augmented Generation - поиск, дополнение, генерация.

Конвейер RAG — путь зелёного запроса Пример: вопрос → находим 3 абзаца из вашей базы → модель отвечает по ним.

⚲ Щёлкните любую станцию - камера приблизит её внутренности. Щёлкните ещё раз внутри - увеличит точные строки. "Отдалить" возвращает обзор.

RETRIEVAL
найти куски
найти нужные куски текста в ваших данных
AUGMENTED
дополнить запрос
добавить найденное прямо в запрос к модели
GENERATION
сформулировать
модель формулирует ответ на основе этих кусков
ПО ФАКТАМ
из документов
модель отвечает по фактам из ваших документов, а не из памяти
