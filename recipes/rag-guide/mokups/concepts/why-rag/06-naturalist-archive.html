Зачем он нужен

Обычная модель не знает ваших данных и со временем устаревает. RAG решает обе проблемы сразу, подкладывая свежие источники в момент ответа.

обзорКарта запроса

Один запрос идёт по цепочке RAG — кликните объект, чтобы приблизиться внутрь Пример: обновили инструкцию в файле — помощник сразу отвечает по новой версии.

Без RAG

  • модель отвечает из устаревшей памяти на момент обучения
  • не найдя источника, выдумывает детали
  • ссылок нет: проверить ответ нечем

С RAG

  • свежие данные из индекса прямо в момент ответа
  • ответ опирается на найденный фрагмент, а не на догадку
  • ссылки видны: понятно, откуда взят ответ
