Картографический реестр · гавань конвейера RAG

Зачем он нужен

Обычная модель не знает ваших данных и со временем устаревает. RAG решает обе проблемы сразу, подкладывая свежие источники в момент ответа. Слева гавань без RAG, справа — с RAG: один зелёный запрос идёт по обеим, и виден весь путь данных от причала с фрагментами до ответа со ссылками.

польза 1
Свежие и приватные данные без переобучения модели
польза 2
Меньше выдуманных фактов — ответ опирается на источник
польза 3
Ссылки на источники: видно, откуда взят ответ
польза 4
Дешевле, чем дообучать модель под каждое обновление
Гавань › ›
С RAG · конвейер Один запрос идёт по видимому маршруту: документы → фрагменты → вектор → индекс → поиск → модель → ответ. Нажмите на причал или склад, чтобы приблизиться.
итог без RAG
Ответ из устаревшей памяти модели: выдуманные детали, серый флаг — сослаться не на что.
итог с RAG
Ответ по свежим источникам из индекса: меньше выдумок, подняты зелёные флаги-ссылки — видно, откуда взят ответ.
зелёный сигнал = ваш запрос

Пример. Обновили инструкцию в файле → помощник сразу отвечает по новой версии. Итог: RAG даёт свежие данные без переобучения, меньше выдуманных фактов и ссылки на источники.
