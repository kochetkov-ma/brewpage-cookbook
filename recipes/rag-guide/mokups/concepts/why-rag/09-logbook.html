Зачем он нужен

Журнал прогона конвейера — зелёный запрос идёт по маршруту

Свежесть · Источники · Цена

Обычная модель не знает ваших данных и со временем устаревает. RAG решает обе проблемы сразу, подкладывая свежие источники в момент ответа.

Прогон одного запроса по конвейеру RAG

зелёный запрос едет по маршруту слева, журнал справа пишется на каждом этапе
Конвейер Нажмите строку журнала — камера приблизится к этому этапу; внутри Индекса есть ещё уровень — точный источник.
причина 1

Свежие данные

Свежие и приватные данные без переобучения модели.

причина 2

Меньше домысла

Меньше выдуманных фактов — ответ опирается на источник.

причина 3

Ссылки

Ссылки на источники: видно, откуда взят ответ.

причина 4

Дешевле

Дешевле, чем дообучать модель под каждое обновление.

Пример: Обновили инструкцию в файле → помощник сразу отвечает по новой версии.

Платформа: brewpage.app · Контракт: github.com/kochetkov-ma/brewpage-openapi

Нажмите строку журнала, чтобы камера приблизилась к этапу конвейера — в записи "Индекс" есть ещё один уровень: точный фрагмент источника.
