Гавань индекса — рейс зелёного запроса по реальным компонентам RAG

Retrieval · поиск по смыслу

Сначала находим релевантные куски текста, потом показываем их модели. Поиск идёт не по точным словам, а по смыслу запроса.

Гавань индекса: запрос -> эмбеддинг -> поиск ближайших -> топ-k -> модель

корабли привозят документы, на причале их режут на фрагменты, каждому присваивается вектор; склад = векторный индекс, кран отбирает топ-3 ближайших по смыслу и отдаёт модели
Масштаб: обзор Гавань
шаг 1

Индекс заранее

Все документы заранее складываем в индекс (векторную базу).

шаг 2

Запрос → вектор

Запрос пользователя превращается в поисковый запрос - вектор смысла.

шаг 3

Топ-k по смыслу

Возвращаем несколько лучших совпадений по смыслу.

итог

Только куски

Модель видит только эти куски, а не весь архив.

Пример: Спросили про отпуск → нашлись пункты политики об отпусках, даже без слова "отпуск".

Нажмите на Эмбеддинг или Индекс - камера приблизится внутрь компонента; там откройте ящик, чтобы прочитать сам фрагмент.
