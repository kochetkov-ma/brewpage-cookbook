Как работает поиск по документам

Сначала находим релевантные куски текста, потом показываем их модели. Поиск идёт не по точным словам, а по смыслу запроса.

  • 1Все документы заранее складываем в индекс
  • 2Запрос пользователя превращается в поисковый запрос
  • 3Возвращаем несколько лучших совпадений по смыслу
  • 4Модель видит только эти куски, а не весь архив
Tabula · Конвейер поиска
Конвейер

Пластина I · Запрос. Зелёный сигнал - ваш запрос. Он идёт по нарисованному маршруту через все стадии. Пластины листаются сами; каждая - реальная стадия конвейера. Дождитесь пластины "Эмбеддинг" и нажмите на её блок (Enter / Space), чтобы приблизить камеру внутрь.

Пример: спросили про отпуск - нашлись пункты политики об отпусках, даже без слова "отпуск" в запросе. Совпадение по смыслу, а не по буквам.
