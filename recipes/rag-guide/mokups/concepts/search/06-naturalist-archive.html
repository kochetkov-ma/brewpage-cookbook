Как работает поиск по документам

Сначала находим релевантные куски текста, потом показываем их модели. Поиск идёт не по точным словам, а по смыслу запроса.

Пример: спросили про отпуск — нашлись пункты политики об отпусках, даже без слова «отпуск».

Доска целикомПуть запроса по смыслу

Зелёный запрос про отпуск идёт слева направо по нарисованному маршруту: 1 запрос → 2 эмбеддинг (вектор) → 3 поиск ближайших в индексе → 4 топ-k фрагментов по смыслу, а не по словам → 5 модель видит только их → 6 ответ со ссылками на карточки.

Нажмите на картотеку (индекс) или любую карточку-фрагмент, чтобы камера приблизилась к объекту. Внутри карточки есть ещё один уровень — точные совпавшие строки. Кнопка Отдалить и крошки вверху возвращают камеру назад.

01 ИНДЕКС
всё заранее
все документы заранее складываем в индекс
02 ЗАПРОС
в эмбеддинг
запрос пользователя превращается в поисковый запрос по смыслу
03 ТОП-K
лучшие по смыслу
возвращаем несколько лучших совпадений по смыслу
04 ТОЛЬКО ИХ
видит модель
модель видит только эти куски, а не весь архив
