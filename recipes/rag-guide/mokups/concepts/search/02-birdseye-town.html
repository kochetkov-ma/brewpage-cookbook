Как работает поиск по документам

Сначала находим релевантные куски текста, потом показываем их модели. Поиск идёт не по точным словам, а по смыслу запроса.

Пример: спросили про отпуск — нашлись пункты политики об отпусках, даже без слова отпуск.

› ›

ПланВесь маршрут поиска

Это один сплошной план поиска по смыслу. Зелёный запрос "что там про отпуск?" выходит из Запроса и едет по нарисованной дороге между настоящими компонентами: Хранилище режет документы на фрагменты, Индекс хранит их как векторы, Поиск берёт ближайшие по смыслу, Модель видит только топ-k фрагментов. Нажмите здание, чтобы приблизить камеру внутрь него.

Увеличение и есть глубина погружения: здание → камера въезжает внутрь (объекты оживают) → внутренний объект → ещё ближе, к векторной карте смысла. Спросили про отпуск — нашёлся пункт политики про отдых даже без слова отпуск. Крошки сверху или кнопка «Отдалить» вернут камеру назад.
