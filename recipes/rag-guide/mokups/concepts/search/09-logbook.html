Как работает поиск по документам

Журнал одного поиска — зелёный запрос идёт по маршруту: запрос → индекс → топ-k → модель → ответ

Индекс · Запрос · Топ-k по смыслу

Сначала находим релевантные куски текста, потом показываем их модели. Поиск идёт не по точным словам, а по смыслу запроса.

Журнал пишет себя сам — а маршрут видно на схеме

зелёный запрос бежит по нарисованному маршруту; строка журнала дописывается, когда он доходит до узла. Нажмите строку — камера приближается к этому шагу.
