# Recipe content essentials

> Pointer-level only. Full guide + DoD: `docs/recipe-authoring.md`.

| Rule | Detail |
|------|--------|
| Teaching artifact | every recipe = interactive teaching artifact; !=blog post |
| Problem-first | open with concrete problem + runnable solution path BEFORE theory |
| Real code | runnable working code; !=pseudocode unless explicitly labelled |
| Interactivity | >=1 interactive element (diagram drill-down, mini-game, calculator, sandbox) |
| Cite claims | every technical claim cites an inline primary source |
| ASCII only | ASCII punctuation -- !=smart quotes / em-dash / unicode dingbats |
| Close strong | end with "try it yourself" / "next steps" pointer |
| Cross-links | mandatory back-links to `https://brewpage.app` + `https://github.com/kochetkov-ma/brewpage-openapi` |
| Role split | CA describes the interactivity; IE implements it -- !=blur the boundary |

Anything not covered here -> `docs/recipe-authoring.md` (authoritative DoD).
